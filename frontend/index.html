Security & compatibility

  • Never commit real API keys to GitHub.
  • Keys entered here remain in this browser profile, but local storage is not a secure vault.
  • GitHub Pages is static hosting; public client-side API calls expose the key to the device user and may be restricted by provider CORS or API policies.
  • For secure public deployment, connect a private backend proxy.
  • Voice input needs browser support and microphone permission.
  • Offline mode caches the app shell; AI and live weather require internet.

Use Chrome’s menu → Install app / Add to Home screen when available.
