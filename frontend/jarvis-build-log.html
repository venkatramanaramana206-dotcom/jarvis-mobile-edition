02 / INSTALLATION

Install Node.js, then open a terminal in your project directory.

npm install npm run build

Start the local development server:

npm run start

03 / ANDROID APK BUILD

For a Capacitor Android build, run:

npx cap add android npx cap sync android

Open the generated Android project in Android Studio and build a debug APK, or use the configured GitHub Actions workflow.

android/app/build/outputs/apk/debug/app-debug.apk

The APK path exists only after a successful build. The first Android setup requires the Android project and build dependencies to be configured.

04 / GITHUB AUTOMATION

Add your Android workflow at:

.github/workflows/build-android.yml

Push your code to GitHub, open the repository's Actions tab, select the Android build workflow, and download the APK artifact from a successful run.

GitHub Actions Guide
