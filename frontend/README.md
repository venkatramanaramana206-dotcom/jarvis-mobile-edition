# J.A.R.V.I.S AI Assistant

A futuristic assistant web app built with HTML, CSS and JavaScript.

## Features

- Futuristic responsive interface
- Live date and time
- Voice input where supported by the browser
- Text command routing
- Weather lookup by city or device location
- NewsAPI integration
- Local audio playback
- Camera preview where browser permissions allow it
- Phone dialer link with confirmation
- Basic single-video trim, crop/fit, text overlay and WebM export
- Web Share API integration where supported
- API settings saved in browser storage
